# LunaUnitFrames-ClassicFix

### Available at Curseforge
[LunaUnitFrames-ClassicFix]https://www.curseforge.com/wow/addons/luna-unit-frames-classic-fix

### This addon supports Classic Era, and TBC Anniversary. This addon does not support WOTLK, CATA, MOP, or RETAIL.
This addon provides continued development of the original https://github.com/Aviana/LunaUnitFrames

This addon is [LunaUnitFrames](https://www.curseforge.com/wow/addons/lunaunitframes) with updated dependencies and bugs fixed. Please report any bugs.

Classic-Fix Updates:
- New Blizzard Castbar API
- Optional Blizzard Heal Prediction
- TBC Anniversary Support
- Better Range finder using LibRangeCheck-3.0
- New Dispels Square Indicator to find debuffs your class can dispel
- Updated to use Blizzard built in Cooldown Count, OmniCC now optional
- Totem Bar with custom colors

LunaUnitFrames supports/recommends WowUp.io for automatic updates: https://wowup.io/
